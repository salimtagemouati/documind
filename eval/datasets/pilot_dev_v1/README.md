# Development pilot v1

This is a separate frozen synthetic dataset containing eleven individually selected development cases from `documind-synthetic-v1` and one new development-only Northbridge policy case. The new case contains genuinely conflicting statements about the same refund deadline, with no stated precedence. The two v1 examples labeled contradictory compare different organizations and are retained as cross-document comparisons. No held-out document, case or label is included or modified.

The 12 selected cases include direct answers, financial and numeric calculations, multi-hop reasoning, three unanswerable questions, cross-document comparison and an explicit same-subject contradiction. One page also contains an adversarial instruction. The curated generation context includes both pages of selected documents; it is an oracle-like context, not a production or SQLite retrieval snapshot. Each answer and page reference requires independent human adjudication before live execution. SHA-256 is recorded in `SHA256`; any change requires a new version. Because this is a nondefault dataset, the live harness also requires `--approve-dataset` after explicit user approval of the synthetic corpus.
