GPT-OSS licensing is confirmed by [OpenAI](https://openai.com/index/introducing-gpt-oss/); [Groq structured outputs](https://console.groq.com/docs/structured-outputs) lists strict support for GPT-OSS and Qwen. Rate figures are provider throughput claims, not measured end-to-end p50/p95. Qwen's context discrepancy needs verification against the account/model API; preview models may be retired at short notice, so it is an experiment, not the preferred production route. [Groq deprecation policy](https://console.groq.com/docs/deprecations) requires ongoing monitoring. [LiteLLM Groq documentation](https://docs.litellm.ai/docs/providers/groq) documents the `groq/` provider route, but the exact pinned SDK/version and model combination has not been tested live.

Example uncached generation only: 4,000 input and 500 output tokens costs $0.00090 (120B), $0.00045 (20B), $0.00520 (Qwen) and $0.00245 (Gemini) at the stated prices. These are hypothetical equal-token scenarios, not measured costs. Actual reasoning tokens, retries, embedding, reranking, analysis calls, prompt caching and provider minimums can change totals. Gemini output pricing includes thinking tokens; verify Groq usage and billing details. [Gemini pricing](https://ai.google.dev/gemini-api/docs/pricing) lists a free tier with eligibility/quotas, and paid content is not used to improve products whereas free-tier content may be. [Gemini limits](https://ai.google.dev/gemini-api/docs/rate-limits) vary by project, model and tier. [Groq rate limits](https://console.groq.com/docs/rate-limits) list free-plan GPT-OSS at 30 RPM, 1,000 RPD, 8,000 TPM and 200,000 TPD; [catalog](https://console.groq.com/docs/models) lists developer-plan 1,000 RPM and 250,000 TPM. Account-specific limits may differ. Free does not guarantee capacity or eligibility.

[Groq data policy](https://console.groq.com/docs/your-data) states inference data can be retained for reliability/abuse monitoring up to 30 days, and customers may enable zero data retention; usage metadata remains collected and retained data resides in the US. Verify organization settings, contractual commitments, regional requirements and model-specific terms. Gemini fallback transfers the same context to Google, so consent and both providers' policies matter.

Recommendation: evaluate GPT-OSS 120B on Groq first: it is production-listed, supports strict JSON, and its posted rates are lower in the illustrative scenario. Compare 20B for cheaper high-volume use and keep Gemini as baseline. Do not switch based on rate cards or provider benchmarks alone. Quality, live JSON behavior, citation accuracy, actual latency, usage, account-specific limits and failover remain unmeasured. Use `ENABLE_GROQ_GPT_OSS=true`, `GROQ_API_KEY`, and optionally `ENABLE_GEMINI_FALLBACK=true`; model IDs are configurable in `backend/.env.example`. The fallback makes one attempt only after transient primary failures; the primary limiter may make up to three attempts at 20 seconds each plus backoff. The API's 90-second outer deadline may cancel earlier. Authentication and other nontransient failures do not fall back. JSON format negotiation and JSON parsing retries can add calls; reranking continues to use `LLM_MODEL` separately. This opt-in path has mock tests only and requires a provider smoke test before deployment. Existing embedding model and dimensions stay unchanged.
